# 주석

## 원칙

- 주석을 쓰지 않는다.
- 함수 사용 방식·동작 설명은 주석 대신 테스트 코드로 작성한다. → [test](test.md)
- JSDoc(`/** */`)을 쓰지 않는다.

## 예외: 태그 주석

꼭 남겨야 할 때만 아래 두 태그를 쓴다.

| 태그 | 언제 | 형식 |
| --- | --- | --- |
| `NOTE` | 코드만으로 알 수 없어 반드시 알아야 할 맥락 | `// NOTE: 내용` |
| `TODO` | 나중에 할 작업 (이슈로 추적) | `// TODO: 내용 (#이슈번호)` |

- 이슈 번호 없는 `TODO`는 쓰지 않는다.
- `FIXME`, `HACK` 등 다른 태그는 쓰지 않는다.
