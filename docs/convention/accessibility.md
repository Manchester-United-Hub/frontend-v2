# 접근성

목표 기준: **WCAG 2.1 AA**

## 이미지 alt

| 이미지 성격 | alt |
| --- | --- |
| 정보 전달 (선수 사진, 엠블럼) | 내용을 설명한다: `alt="맨체스터 유나이티드 엠블럼"` |
| 장식 | `alt=""` (생략하지 않고 빈 문자열) |

## 시맨틱 태그

- 레이아웃은 `<header>`, `<nav>`, `<main>`, `<footer>`를 쓴다.
- `<h1>`은 페이지당 1개, 제목 레벨을 건너뛰지 않는다. (`h2` → `h4` ✗)
- 이동은 `<Link>`, 동작은 `<button>`을 쓴다. `<div onClick>`을 쓰지 않는다.

## 키보드 조작

- 모든 인터랙션은 Tab으로 도달하고 Enter/Space로 동작해야 한다.
- 포커스 표시를 제거하지 않는다.
- `tabIndex`에 양수를 쓰지 않는다.

## 색에만 의존 금지

- 의미를 색만으로 구분하지 않는다. 예: 승/무/패는 색과 함께 텍스트(`W`/`D`/`L`)를 병기한다.

## 명도 대비

- 일반 텍스트 4.5:1 이상, 큰 텍스트(24px 이상 또는 bold 18.66px 이상)와 아이콘·테두리 3:1 이상.
- 브랜드 레드 위 텍스트 등 배경색이 있는 조합은 대비를 확인한다.

## ARIA

| 상황 | 규칙 |
| --- | --- |
| 아이콘만 있는 버튼 | `aria-label` 필수 |
| 현재 메뉴 | 활성 링크에 `aria-current="page"` |
| 더보기로 항목 추가 | 목록 영역에 `aria-live="polite"` |

## 동작 줄이기

- 사용자가 OS에서 "동작 줄이기"를 켜면 애니메이션을 끈다.
- `motion`은 `useReducedMotion`, Tailwind는 `motion-reduce:`를 쓴다.

## 페이지 공통

- `<html lang="ko">`
- 페이지 맨 앞에 "본문으로 건너뛰기" 링크를 둔다.
- 터치 영역은 최소 24×24px, 권장 44×44px.
